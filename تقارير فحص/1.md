## 🔧 الإصلاح #1: جدول `inventory_balances`

### المشكلة بالتفصيل

**الكود الحالي** في `InventoryService::availableQuantity()`:

```php
public function availableQuantity(int $itemId, int $warehouseId, ?int $unitId = null): float
{
    static $cache = [];
    $key = "{$itemId}:{$warehouseId}:" . ($unitId ?? 'null');

    if (array_key_exists($key, $cache)) {
        return $cache[$key];
    }

    $in = InventoryMovementDetail::query()
        ->join('inventory_movements', ...)
        ->where('item_id', $itemId)
        ->where('warehouse_id', $warehouseId)
        ->where('direction', 'in')
        ->sum('quantity');

    $out = InventoryMovementDetail::query()
        ->where('direction', 'out')
        ->sum('quantity');

    return $cache[$key] = (float) $in - (float) $out;
}
```

### لماذا هذا الكود خطير؟

**السبب 1 — الأداء O(n):**

| عدد الحركات للصنف | زمن الاستعلام |
|-------------------|---------------|
| 1,000 | ~15ms ✅ |
| 10,000 | ~80ms ⚠️ |
| 100,000 | ~400ms ❌ |
| 1,000,000 | ~4 ثواني 💥 |

**مع فاتورة 20 صف:** 20 × 400ms = **8 ثواني** فقط لفحص الرصيد.

**السبب 2 — `static $cache` مسموم:**

```php
// في نفس الطلب:
$available = $service->availableQuantity(1, 1, 1); // = 100

// ثم نُنشئ حركة OUT:
$movement = InventoryMovement::create(['direction' => 'out', ...]);
InventoryMovementDetail::create([..., 'quantity' => 20]);

// استدعاء ثانٍ:
$available2 = $service->availableQuantity(1, 1, 1);
// ⚠️ يُرجع 100 (القيمة القديمة من الـ cache) بدل 80!
```

**النتيجة:** النظام "يرى" رصيداً قديماً → يسمح ببيع أكثر من المتوفر → كوارث محاسبية.

### ✅ الحل: جدول `inventory_balances`

**الفكرة المعمارية:**

```
inventory_movements  →  المصدر الحقيقي (Source of Truth) للأوديت
        ↓ (يُحدَّث تلقائياً عند أي حركة)
inventory_balances   →  Materialized View (نسخة مُجمَّعة)
```

- **لا نُلغي الحركات** — تبقى كسجل تاريخي كامل.
- **نضيف جدول أرصدة** — للحساب السريع O(1).
- **التزامن تلقائي** عبر `applyMovement` / `reverseMovement`.

### 📁 الملف 1.3: Service مُعدَّل

**الموقع:** `app/Services/Inventory/InventoryService.php` (استبدل الدوال القديمة)

**⚠️ ملاحظة مهمة:** سنُعيد كتابة `availableQuantity` و `lastCost` و `applyMovement` و `reverseMovement`. باقي الدوال (`currentUnitCost`، `lastPricing`، `sortInventory`) تبقى كما هي مبدئياً.

```php
<?php

namespace App\Services\Inventory;

use App\Models\Inventory\InventoryBalance;
use App\Models\Inventory\InventoryMovement;
use App\Models\Inventory\InventoryMovementDetail;
use Illuminate\Support\Facades\DB;
use Illuminate\Validation\ValidationException;

class InventoryService
{
    // =====================================================
    // ✅ القراءة من جدول الأرصدة (O(1))
    // =====================================================

    /**
     * الكمية المتوفرة — قراءة مباشرة من جدول الأرصدة
     *
     * ✅ O(1) — index lookup
     * ✅ unit-aware + type-aware
     * ✅ لا static cache — القيمة دائماً صحيحة
     */
    public function availableQuantity(
        int $itemId,
        int $warehouseId,
        ?int $unitId = null,
        ?int $typeId = null
    ): float {
        return (float) InventoryBalance::query()
            ->where('item_id', $itemId)
            ->where('warehouse_id', $warehouseId)
            ->when($unitId !== null,  fn($q) => $q->where('unit_id', $unitId))
            ->when($unitId === null,  fn($q) => $q->whereNull('unit_id'))
            ->when($typeId !== null,  fn($q) => $q->where('type_id', $typeId))
            ->when($typeId === null,  fn($q) => $q->whereNull('type_id'))
            ->value('quantity') ?? 0;
    }

    /**
     * ✅ النسخة Batch — Query واحد لكل الأصناف
     *
     * @param array $keys = [
     *   ['item_id'=>1, 'warehouse_id'=>1, 'unit_id'=>2, 'type_id'=>null],
     *   ...
     * ]
     * @return array ["itemId:warehouseId:unitId:typeId" => quantity]
     */
    public function availableQuantitiesBatch(array $keys): array
    {
        if (empty($keys)) {
            return [];
        }

        $itemIds = collect($keys)->pluck('item_id')->unique()->filter()->toArray();
        $whIds   = collect($keys)->pluck('warehouse_id')->unique()->filter()->toArray();

        if (empty($itemIds) || empty($whIds)) {
            return [];
        }

        $balances = InventoryBalance::query()
            ->whereIn('item_id', $itemIds)
            ->whereIn('warehouse_id', $whIds)
            ->get()
            ->keyBy(function ($b) {
                $u = $b->unit_id ?? 'null';
                $t = $b->type_id ?? 'null';
                return "{$b->item_id}:{$b->warehouse_id}:{$u}:{$t}";
            });

        $result = [];
        foreach ($keys as $k) {
            $u = $k['unit_id'] ?? 'null';
            $t = $k['type_id'] ?? 'null';
            $key = "{$k['item_id']}:{$k['warehouse_id']}:{$u}:{$t}";
            $result[$key] = (float) ($balances[$key]->quantity ?? 0);
        }

        return $result;
    }

    /**
     * هل الكمية المطلوبة متوفرة؟
     */
    public function isAvailable(
        int $itemId,
        int $warehouseId,
        float $qty,
        ?int $unitId = null,
        ?int $typeId = null
    ): bool {
        return $this->availableQuantity($itemId, $warehouseId, $unitId, $typeId) >= $qty;
    }

    /**
     * آخر تكلفة (متوسط مرجّح) — من جدول الأرصدة
     */
    public function lastCost(
        int $itemId,
        int $warehouseId,
        ?int $unitId = null,
        ?int $typeId = null
    ): float {
        return (float) InventoryBalance::query()
            ->where('item_id', $itemId)
            ->where('warehouse_id', $warehouseId)
            ->when($unitId !== null, fn($q) => $q->where('unit_id', $unitId))
            ->when($unitId === null, fn($q) => $q->whereNull('unit_id'))
            ->when($typeId !== null, fn($q) => $q->where('type_id', $typeId))
            ->when($typeId === null, fn($q) => $q->whereNull('type_id'))
            ->value('avg_cost') ?? 0;
    }

    /**
     * ✅ Batch version من lastCost
     * @return array ["itemId:warehouseId:unitId" => avg_cost]
     */
    public function lastCostsBatch(array $keys): array
    {
        if (empty($keys)) {
            return [];
        }

        $itemIds = collect($keys)->pluck('item_id')->unique()->filter()->toArray();
        $whIds   = collect($keys)->pluck('warehouse_id')->unique()->filter()->toArray();

        if (empty($itemIds) || empty($whIds)) {
            return [];
        }

        $balances = InventoryBalance::query()
            ->whereIn('item_id', $itemIds)
            ->whereIn('warehouse_id', $whIds)
            ->get()
            ->keyBy(function ($b) {
                $u = $b->unit_id ?? 'null';
                return "{$b->item_id}:{$b->warehouse_id}:{$u}";
            });

        $result = [];
        foreach ($keys as $k) {
            $u = $k['unit_id'] ?? 'null';
            $key = "{$k['item_id']}:{$k['warehouse_id']}:{$u}";
            $result[$key] = (float) ($balances[$key]->avg_cost ?? 0);
        }

        return $result;
    }

    // =====================================================
    // ✅ الكتابة — التحديث الفعلي للأرصدة
    // =====================================================

    /**
     * تطبيق حركة على الأرصدة
     *
     * يُستدعى بعد إنشاء حركة (movement) + تفاصيلها
     *
     * ⚠️ يجب أن يكون داخل transaction
     */
    public function applyMovement(InventoryMovement $movement): void
    {
        $movement->loadMissing('details');

        $sign = $movement->direction === InventoryMovement::DIRECTION_IN ? 1 : -1;

        foreach ($movement->details as $detail) {
            $this->adjustBalance(
                (int) $detail->item_id,
                (int) $detail->warehouse_id,
                $detail->unit_id !== null ? (int) $detail->unit_id : null,
                $detail->type_id !== null ? (int) $detail->type_id : null,
                $sign * (float) $detail->quantity,
                $sign * (float) $detail->total
            );
        }
    }

    /**
     * عكس حركة قبل حذفها
     *
     * ⚠️ يجب أن يكون داخل transaction
     */
    public function reverseMovement(InventoryMovement $movement): void
    {
        $movement->loadMissing('details');

        // عكس الاتجاه
        $sign = $movement->direction === InventoryMovement::DIRECTION_IN ? -1 : 1;

        foreach ($movement->details as $detail) {
            $this->adjustBalance(
                (int) $detail->item_id,
                (int) $detail->warehouse_id,
                $detail->unit_id !== null ? (int) $detail->unit_id : null,
                $detail->type_id !== null ? (int) $detail->type_id : null,
                $sign * (float) $detail->quantity,
                $sign * (float) $detail->total
            );
        }
    }

    /**
     * ✅ التعديل الذري على الرصيد (Atomic)
     *
     * يستخدم UPDATE ... SET quantity = quantity + delta
     * لمنع Race Conditions
     */
    private function adjustBalance(
        int $itemId,
        int $warehouseId,
        ?int $unitId,
        ?int $typeId,
        float $deltaQty,
        float $deltaCost
    ): void {
        // 1. بناء شرط WHERE بمفاتيح مركبة
        $whereClosure = function ($q) use ($itemId, $warehouseId, $unitId, $typeId) {
            $q->where('item_id', $itemId)
              ->where('warehouse_id', $warehouseId);

            if ($unitId === null) {
                $q->whereNull('unit_id');
            } else {
                $q->where('unit_id', $unitId);
            }

            if ($typeId === null) {
                $q->whereNull('type_id');
            } else {
                $q->where('type_id', $typeId);
            }
        };

        // 2. محاولة التحديث أولاً (Atomic increment)
        $updated = DB::table('inventory_balances')
            ->where($whereClosure)
            ->update([
                'quantity'   => DB::raw("quantity + ({$deltaQty})"),
                'total_cost' => DB::raw("total_cost + ({$deltaCost})"),
                'updated_at' => now(),
            ]);

        // 3. لو لم يوجد صف، أنشئه
        if ($updated === 0) {
            try {
                DB::table('inventory_balances')->insert([
                    'item_id'      => $itemId,
                    'warehouse_id' => $warehouseId,
                    'unit_id'      => $unitId,
                    'type_id'      => $typeId,
                    'quantity'     => $deltaQty,
                    'total_cost'   => $deltaCost,
                    'avg_cost'     => $deltaQty != 0 ? $deltaCost / $deltaQty : 0,
                    'created_at'   => now(),
                    'updated_at'   => now(),
                ]);
            } catch (\Illuminate\Database\QueryException $e) {
                // Race condition: صف أُنشئ بين الـ UPDATE والـ INSERT
                // أعد المحاولة (الـ UPDATE هذه المرة سينجح)
                if ($e->errorInfo[1] === 1062) { // Duplicate entry
                    DB::table('inventory_balances')
                        ->where($whereClosure)
                        ->update([
                            'quantity'   => DB::raw("quantity + ({$deltaQty})"),
                            'total_cost' => DB::raw("total_cost + ({$deltaCost})"),
                            'updated_at' => now(),
                        ]);
                } else {
                    throw $e;
                }
            }
        }

        // 4. تحديث avg_cost دائماً بعد التعديل
        DB::table('inventory_balances')
            ->where($whereClosure)
            ->where('quantity', '>', 0)
            ->update([
                'avg_cost' => DB::raw("total_cost / quantity"),
            ]);
    }
}
```

**ملاحظات للمراجعة:**
- استخدمنا `updateOrInsert` يدوياً بدل `upsert` لدعم `NULL` في unique key (MySQL لا يعتبر NULL = NULL في unique).
- `DB::raw("quantity + ({$deltaQty})")` آمن لأن `$deltaQty` رقم float تم cast.
- التحقق من duplicate entry يحل حالة race عند أول إدراج.

### 📁 الملف 1.4: Backfill Script

**الموقع:** `database/migrations/2026_10_01_000002_backfill_inventory_balances.php`

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Support\Facades\DB;

return new class extends Migration
{
    public function up(): void
    {
        // حساب الأرصدة من الحركات الموجودة
        // تنبيه: قد يستغرق دقائق على بيانات ضخمة
        DB::statement("
            INSERT INTO inventory_balances
                (item_id, warehouse_id, unit_id, type_id,
                 quantity, total_cost, avg_cost, created_at, updated_at)
            SELECT
                imd.item_id,
                imd.warehouse_id,
                imd.unit_id,
                imd.type_id,
                SUM(CASE WHEN im.direction = 'in'
                         THEN imd.quantity
                         ELSE -imd.quantity
                    END) AS quantity,
                SUM(CASE WHEN im.direction = 'in'
                         THEN imd.total
                         ELSE -imd.total
                    END) AS total_cost,
                CASE
                    WHEN SUM(CASE WHEN im.direction = 'in'
                                  THEN imd.quantity
                                  ELSE -imd.quantity
                             END) > 0
                    THEN
                        SUM(CASE WHEN im.direction = 'in'
                                 THEN imd.total
                                 ELSE -imd.total
                            END)
                        /
                        SUM(CASE WHEN im.direction = 'in'
                                 THEN imd.quantity
                                 ELSE -imd.quantity
                            END)
                    ELSE 0
                END AS avg_cost,
                NOW(),
                NOW()
            FROM inventory_movement_details imd
            JOIN inventory_movements im
              ON im.movement_id = imd.movement_id
            GROUP BY
                imd.item_id,
                imd.warehouse_id,
                imd.unit_id,
                imd.type_id
        ");
    }

    public function down(): void
    {
        DB::table('inventory_balances')->truncate();
    }
};
```

**ملاحظات:**
- استخدم `GROUP BY` على 4 مفاتيح لتوليد صف واحد لكل مزيج.
- `SUM(CASE ...)` يحسب الأرصدة ذكياً.
- إن فشل على بيانات ضخمة، قسّم على دفعات (chunk) بـ `LIMIT` و `OFFSET`.

### 📁 الملف 2.2: Service

**الموقع:** `app/Services/SequenceService.php`

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\DB;

class SequenceService
{
    /**
     * ✅ استخراج الرقم التالي بشكل ذري (Atomic)
     *
     * يعمل عبر UPDATE ... SET next_value = next_value + step
     * وهو atomic على مستوى الصف في MySQL/MariaDB
     */
    public function next(string $key, int $step = 1): int
    {
        return DB::transaction(function () use ($key, $step) {
            // 1. تأكد من وجود الصف
            $exists = DB::table('sequences')->where('key', $key)->exists();

            if (!$exists) {
                DB::table('sequences')->insertOrIgnore([
                    'key'        => $key,
                    'next_value' => 1,
                    'created_at' => now(),
                    'updated_at' => now(),
                ]);
            }

            // 2. UPDATE ذري
            DB::table('sequences')
                ->where('key', $key)
                ->update([
                    'next_value' => DB::raw("next_value + {$step}"),
                    'updated_at' => now(),
                ]);

            // 3. اقرأ القيمة الجديدة
            $value = (int) DB::table('sequences')
                ->where('key', $key)
                ->value('next_value');

            return $value - $step;
        });
    }

    /**
     * ✅ استخراج رقم ببادئة (مثل SORT-000001)
     */
    public function nextWithPrefix(string $key, string $prefix, int $padLength = 6): string
    {
        $num = $this->next($key);
        return $prefix . str_pad((string) $num, $padLength, '0', STR_PAD_LEFT);
    }

    /**
     * ✅ الحصول على القيمة الحالية دون زيادة (للعرض)
     */
    public function current(string $key): int
    {
        return (int) DB::table('sequences')
            ->where('key', $key)
            ->value('next_value') ?? 1;
    }

    /**
     * ✅ إعادة ضبط (إداري فقط)
     */
    public function reset(string $key, int $value = 1): void
    {
        DB::table('sequences')
            ->where('key', $key)
            ->update(['next_value' => $value, 'updated_at' => now()]);
    }
}
```

## 🔧 الإصلاح #4: SoftDeletes + Audit Columns

### المشكلة

حذف فاتورة = حذف نهائي. **في ERP، هذا مرفوض.**
- لا يمكن استرجاع البيانات
- لا يوجد سجل (Audit Trail)
- مستقبلاً مع صلاحيات، لن نعرف من حذف

### ✅ الحل

### 📁 Migration

**الموقع:** `database/migrations/2026_10_01_000004_add_soft_deletes_and_audit_columns.php`

```php
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

    private array $tables = [
        'sales_invoices',
        'sales_invoice_details',
        'purchase_invoices',

            Schema::table($table, function (Blueprint $t) use ($table) {
                if (!Schema::hasColumn($table, 'deleted_at')) {
                    $t->softDeletes();
                    $t->index('deleted_at', "idx_{$table}_deleted_at");
                }

                if (!Schema::hasColumn($table, 'created_by')) {
                    $t->unsignedBigInteger('created_by')->nullable()
                      ->comment('معرف المستخدم المنشئ');
                }

                if (!Schema::hasColumn($table, 'updated_by')) {
                    $t->unsignedBigInteger('updated_by')->nullable()
                      ->comment('معرف المستخدم المُحدِّث');
                }

                if (!Schema::hasColumn($table, 'deleted_by')) {
                    $t->unsignedBigInteger('deleted_by')->nullable()
                      ->comment('معرف المستخدم الحاذف');
                }
            });
        }
    }

    public function down(): void
    {
        foreach ($this->tables as $table) {
            if (!Schema::hasTable($table)) continue;

            Schema::table($table, function (Blueprint $t) use ($table) {
                $columns = [];

                foreach (['deleted_at', 'created_by', 'updated_by', 'deleted_by'] as $col) {

                            $t->dropIndex("idx_{$table}_deleted_at");
                        }
                        $columns[] = $col;
```

```php
trait GeneratesAccountCodes
{
    protected function getParentAccount(string $systemKey): ?CharAccount

        return CharAccount::where('system_key', $systemKey)

    /**
     * ✅ توليد كود الحساب الفرعي التالي — Query واحد
     *
     * بدل تحميل كل الأبناء في PHP (بطيء)

    protected function generateNextChildCode(CharAccount $parent): string
    {
        $prefix = $parent->accCode;
        $prefixLen = strlen($prefix);

        // استعلام واحد فقط
        $maxSuffix = CharAccount::where('accParent', $parent->accountID)
            ->where('isPostable', 1)
            ->where('accCode', 'like', $prefix . '%')
            ->selectRaw(
                "MAX(CAST(SUBSTRING(accCode, ?) AS UNSIGNED)) as max_suffix",
                [$prefixLen + 1]
            )
            ->value('max_suffix') ?? 0;

        return $prefix . str_pad(
            (string)($maxSuffix + 1),
            2,
            '0',
            STR_PAD_LEFT
        );
    }
```

```php
            )
            ->when($filters['search_phone'] ?? null, fn($q, $v) =>
                $q->where('CusPhone', 'like', "%{$v}%")

            ->when($filters['search_code'] ?? null, fn($q, $v) =>

                )

            ->paginate($filters['per_page'] ?? 50);

            ->when($term !== '', function ($q) use ($term) {

                    $sub->where('CustomersName2', 'like', "%{$term}%")
                        ->orWhereHas('account', fn($a) =>
                            $a->where('accCode', 'like', "%{$term}%")
                        );
                });
            })
            ->orderByDesc('CustomersID')
            ->limit($limit)
            ->get()

                'CusIsStopeed'   => $data['CusIsStopeed'] ?? 0,
            ]);

            return ['customer' => $customer, 'account' => $account];
        });
    }

    public function update(int $id, array $data): Customer
    {
        return DB::transaction(function () use ($id, $data) {
            $customer = Customer::findOrFail($id);

            $customer->update([
                'CustomersName2' => $data['CustomersName2'],
                'CusPhone'       => $data['CusPhone'] ?? null,
                'CusAddress'     => $data['CusAddress'] ?? null,
                'CusIsStopeed'   => $data['CusIsStopeed'] ?? 0,
            ]);

            // Observer يتولى مزامنة الحساب
            return $customer->fresh('account');
        });
    }

    public function delete(int $id): void
    {
        DB::transaction(function () use ($id) {
            $customer = Customer::findOrFail($id);
            $accountId = $customer->accountID;

            $customer->delete();

            if ($accountId) {
                $account = CharAccount::find($accountId);
                if (!$account) return;

                $hasChildren = CharAccount::where('accParent', $accountId)->exists();

                if ($hasChildren) {
                    $account->update(['IsActive' => 0]);
                } else {
                    $account->delete();
                }
            }
        });
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Services\CustomerService;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

class CustomerController extends Controller
{
    public function __construct(
        private readonly CustomerService $service

    }

    {
        return $this->paginatedResponse(

                'search_name', 'search_phone', 'search_code', 'per_page',
            ]))
        );

    {
        return $this->successResponse(
            $this->service->search(trim($request->input('search', '')))
        );
    }

    public function show(int|string $id)
    {
        $customer = $this->service->find($id);

        if (!$customer) {
            return $this->errorResponse('العميل غير موجود', [], 404);
        }

        return $this->successResponse($customer);
    }

    public function store(Request $request)
    {
        $data = $request->validate([
            'CustomersName2' => ['required', 'string', 'max:255'],
            'CusPhone'       => ['nullable', 'string', 'max:50'],
            'CusAddress'     => ['nullable', 'string', 'max:500'],
            'CusIsStopeed'   => ['nullable', 'integer', 'in:0,1'],
        ]);

        $result = $this->service->create($data);

        return $this->successResponse([
            'CustomersID'    => $result['customer']->CustomersID,
            'CustomersName2' => $result['customer']->CustomersName2,
            'accountID'      => $result['account']->accountID,
            'accountCode'    => $result['account']->accCode,
        ], 'تم إضافة العميل بنجاح', 201);
    }

    public function update(Request $request, int|string $id)
    {
        $data = $request->validate([
            'CustomersName2' => ['required', 'string', 'max:255'],
            'CusPhone'       => ['nullable', 'string', 'max:50'],
            'CusAddress'     => ['nullable', 'string', 'max:500'],
            'CusIsStopeed'   => ['nullable', 'integer', 'in:0,1'],
        ]);

        $this->service->update((int) $id, $data);

        return $this->successResponse(null, 'تم تحديث العميل بنجاح');
    }

    public function destroy(int|string $id)
    {
        try {
            $this->service->delete((int) $id);
            return $this->successResponse(null, 'تم حذف العميل بنجاح');
        } catch (\Illuminate\Database\QueryException $e) {
            if ($e->errorInfo[1] === 1451) {  // FK constraint
                return $this->errorResponse(
                    'لا يمكن حذف العميل لوجود حركات مرتبطة به',
                    [],
                    422
                );
            }
            throw $e;
        }
    }
}
```
