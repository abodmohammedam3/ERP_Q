## 🔧 التحسين #1: BaseController

### 📁 الملف

**الموقع:** `app/Http/Controllers/Controller.php`

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Contracts\Pagination\LengthAwarePaginator;
use Illuminate\Http\JsonResponse;

/**
 * ✅ Base Controller
 *
 * كل Controllers في النظام يجب أن ترث من هذا.
 *
 * القواعد:
 *   1. لا DB:: مباشرة في Controllers
 *   2. لا Validator::make مباشرة (استخدم FormRequest)
 *   3. كل رد عبر successResponse/errorResponse/paginatedResponse
 *   4. Controller يجب أن يبقى ≤ 100 سطر
 */
abstract class Controller
{
    /**
     * رد نجاح موحّد
     */
    protected function successResponse(
        mixed $data = null,
        string $message = 'تمت العملية بنجاح',
        int $code = 200
    ): JsonResponse {
        return response()->json([
            'success' => true,
            'message' => $message,
            'data'    => $data,
        ], $code);
    }

    /**
     * رد خطأ موحّد
     */
    protected function errorResponse(
        string $message,
        array $errors = [],
        int $code = 400
    ): JsonResponse {
        return response()->json([
            'success' => false,
            'message' => $message,
            'errors'  => $errors,
        ], $code);
    }

    /**
     * رد نجاح مع Pagination
     */
    protected function paginatedResponse(
        LengthAwarePaginator $paginator,
        string $message = 'تم التحميل'
    ): JsonResponse {
        return response()->json([
            'success' => true,
            'message' => $message,
            'data'    => $paginator->items(),
            'meta'    => [
                'current_page' => $paginator->currentPage(),
                'per_page'     => $paginator->perPage(),
                'total'        => $paginator->total(),
                'last_page'    => $paginator->lastPage(),
                'from'         => $paginator->firstItem(),
                'to'           => $paginator->lastItem(),
            ],
        ]);
    }

    /**
     * رد إنشاء (201)
     */
    protected function createdResponse(
        mixed $data,
        string $message = 'تم الإنشاء بنجاح'
    ): JsonResponse {
        return $this->successResponse($data, $message, 201);
    }

    /**
     * رد حذف
     */
    protected function noContentResponse(
        string $message = 'تم الحذف بنجاح'
    ): JsonResponse {
        return $this->successResponse(null, $message);
    }
}
```

### 🎯 الفوائد

**قبل — كل Controller يعيد:**
```php
return response()->json(['success' => true, 'data' => $x]);
return response()->json(['message' => 'ok', 'data' => $x]);
return response()->json(['status' => 'ok', 'result' => $x]);
```

**بعد — نمط واحد:**
```php
return $this->successResponse($x);
```

### ⚠️ ملاحظة للتوافقية

الـ Frontend الحالي يتوقع `{data: []}` أو `{customers: []}`. **التحويل التدريجي:**

1. في **المرحلة 3**: نستخدم `BaseController` للـ endpoints الجديدة
2. بعد استقرار الواجهات: نحوّل الـ endpoints القديمة دفعة واحدة
3. **لا نكسر الواجهات الحالية** — نُحافظ على contract مؤقتاً

**الحل**: نضيف method خاص:
```php
protected function legacyResponse(array $data): JsonResponse
{
    return response()->json($data);  // للتوافقية
}
```

## 🔧 التحسين #2: BaseService

### 📁 الملف

**الموقع:** `app/Services/BaseService.php`

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

/**
 * ✅ Base Service
 *
 * كل Services في النظام يجب أن ترث من هذا.
 *
 * المزايا:
 *   - transaction() موحّد مع logging تلقائي
 *   - معايير الاستثناءات
 *   - تسهيل الـ testing
 */
abstract class BaseService
{
    /**
     * تنفيذ عملية داخل transaction
     *
     * الفوائد:
     *   - Rollback تلقائي عند الفشل
     *   - تسجيل الأخطاء تلقائياً
     *   - Nested transactions (savepoints)
     */
    protected function transaction(
        callable $callback,
        string $context = ''
    ): mixed {
        try {
            return DB::transaction($callback);
        } catch (\Throwable $e) {
            if ($context !== '') {
                Log::error("Service transaction failed: {$context}", [
                    'message' => $e->getMessage(),
                    'file'    => $e->getFile(),
                    'line'    => $e->getLine(),
                ]);
            }
            throw $e;
        }
    }
}
```

### 🎯 الاستخدام

**قبل:**
```php
public function create(Request $request): SalesInvoice
{
    return DB::transaction(function () use ($request) {
        try {
            // ... منطق طويل
        } catch (\Throwable $e) {
            Log::error('Sales create failed', [...]);
            throw $e;
        }
    });
}
```

**بعد:**
```php
public function create(array $data): SalesInvoice
{
    return $this->transaction(function () use ($data) {
        // ... منطق طويل
    }, 'SalesInvoice::create');
}
```

<?php

namespace App\Http\Requests\Sales;

use App\Enums\PaymentMethod;
use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Validation\Rule;

class StoreSalesInvoiceRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;  // single-user حالياً
    }

    public function rules(): array
    {
        return [
            'invoice_date' => ['required', 'date'],

            'account_id' => [
                'required', 'integer',
                'exists:characcount,accountID',
            ],

            'payment_method' => [
                'required', 'integer',
                Rule::enum(PaymentMethod::class),
            ],

            'coin_id' => [
                'required', 'integer',
                'exists:coins,coinsID',
            ],

            'exchange_rate' => ['nullable', 'numeric', 'min:0'],

            'payment_account_id' => [
                'nullable', 'integer',
                'exists:characcount,accountID',
            ],

            'statement' => ['nullable', 'string', 'max:2000'],
            'reference' => ['nullable', 'string', 'max:2000'],

            // ─── التفاصيل ───
            'details' => ['required', 'array', 'min:1'],

            'details.*.item_id' => [
                'required', 'integer',
                'exists:Items,itemID',
            ],

            'details.*.type_id' => [
                'nullable', 'integer',
                'exists:type,id',
            ],

            'details.*.unit_id' => [
                'nullable', 'integer',
                'exists:units,UnitID',
            ],

            'details.*.warehouse_id' => [
                'required', 'integer',
                'exists:stocks,StockID',
            ],

            'details.*.code' => ['nullable', 'string', 'max:50'],

            'details.*.quantity' => ['required', 'numeric', 'gt:0'],

            'details.*.price' => ['required', 'numeric', 'gt:0'],

            'details.*.cost_price' => ['nullable', 'numeric', 'min:0'],

            'details.*.discount' => ['nullable', 'numeric', 'min:0'],
        ];
    }

    /**
     * ✅ قواعد معقدة بعد التحقق الأساسي
     */
    public function withValidator($validator): void
    {
        $validator->after(function ($v) {

            // ─── 1. فحص طريقة الدفع ───
            $method = PaymentMethod::tryFrom((int) $this->input('payment_method'));
            $paymentAccount = $this->input('payment_account_id');

            if ($method === PaymentMethod::Credit && !empty($paymentAccount)) {
                $v->errors()->add(
                    'payment_account_id',
                    'طريقة الدفع "آجل" لا تحتاج إلى حساب دفع'
                );
            }

            if ($method && $method->requiresPaymentAccount() && empty($paymentAccount)) {
                $v->errors()->add(
                    'payment_account_id',
                    'يجب اختيار حساب الدفع'
                );
            }

            // ─── 2. فحص كل صف ───
            foreach ($this->input('details', []) as $i => $row) {
                $qty      = (float) ($row['quantity'] ?? 0);
                $price    = (float) ($row['price'] ?? 0);
                $discount = (float) ($row['discount'] ?? 0);

                if ($discount > $qty * $price) {
                    $v->errors()->add(
                        "details.{$i}.discount",
                        'الخصم لا يمكن أن يتجاوز قيمة الصف'
                    );
                }

                if (max(0, $qty * $price - $discount) <= 0) {
                    $v->errors()->add(
                        "details.{$i}.price",
                        'إجمالي الصف يجب أن يكون أكبر من صفر'
                    );
                }
            }
        });
    }

    public function messages(): array
    {
        return [
            'invoice_date.required'  => 'تاريخ الفاتورة مطلوب',
            'invoice_date.date'      => 'تاريخ الفاتورة غير صحيح',

            'account_id.required'    => 'يجب اختيار العميل',
            'account_id.exists'      => 'العميل المحدد غير موجود',

            'payment_method.required'=> 'طريقة الدفع مطلوبة',
            'payment_method.integer' => 'طريقة الدفع غير صحيحة',

            'coin_id.required'       => 'يجب اختيار العملة',
            'coin_id.exists'         => 'العملة المحددة غير موجودة',

            'details.required'       => 'يجب إضافة صنف واحد على الأقل',
            'details.min'            => 'يجب إضافة صنف واحد على الأقل',

            'details.*.item_id.required'      => 'يجب اختيار الصنف في كل الصفوف',
            'details.*.item_id.exists'        => 'أحد الأصناف المحددة غير موجود',
            'details.*.warehouse_id.required' => 'يجب اختيار المخزن في كل الصفوف',
            'details.*.warehouse_id.exists'   => 'أحد المخازن المحددة غير موجود',
            'details.*.quantity.gt'           => 'الكمية يجب أن تكون أكبر من صفر',
            'details.*.price.gt'              => 'سعر الوحدة يجب أن يكون أكبر من صفر',
        ];
    }

    /**
     * ✅ تخصيص أسماء الحقول للرسائل
     */
    public function attributes(): array
    {
        return [
            'account_id'         => 'العميل',
            'payment_method'     => 'طريقة الدفع',
            'coin_id'            => 'العملة',
            'payment_account_id' => 'حساب الدفع',
            'details.*.item_id'  => 'الصنف',
            'details.*.quantity' => 'الكمية',
            'details.*.price'    => 'السعر',
        ];
    }
}

| `whereNumber('id')` | أمان + تجنب conflict |
| Static قبل `{id}` | منع الالتباس |
| `kebab-case` في URLs | معيار الويب |
| `dot.notation` في names | معيار Laravel |

## 📝 الملف 9: JavaScript

**`resources/js/{domain}/{entity}.js`**

```javascript
/**
 * {Entity} Module
 */

const {Entity}Module = (() => {

    const API_BASE = '/{domain}/{entity}';
    let csrfToken = document.querySelector('meta[name="csrf-token"]')?.content;

    let currentPage = 1;
    let deleteId = null;
    let searchTimeout = null;

    // ══════════════════════════════════════════════
    //  Load Data
    // ══════════════════════════════════════════════
    async function loadData(page = 1) {
        currentPage = page;

        const params = new URLSearchParams({
            page,
            per_page: 50,
            search: document.getElementById('search-input')?.value || '',
            status: document.getElementById('status-filter')?.value || '',
        });

        try {
            const res = await fetch(`${API_BASE}/list?${params}`);
            const json = await res.json();

            renderTable(json.data);
            renderPagination(json.meta);
        } catch (err) {
            showError('فشل تحميل البيانات');
        }
    }

    // ══════════════════════════════════════════════
    //  Render
    // ══════════════════════════════════════════════
    function renderTable(items) {
        const tbody = document.getElementById('{entity}-tbody');
        if (!tbody) return;

        if (items.length === 0) {
            tbody.innerHTML = '<tr><td colspan="5" class="text-center">لا توجد بيانات</td></tr>';
            return;
        }

        tbody.innerHTML = items.map((item, i) => `
            <tr>
                <td>${i + 1}</td>
                <td>${escapeHtml(item.name)}</td>
                <td>${escapeHtml(item.code || '')}</td>
                <td>${item.status === 1 ? '<span class="badge bg-success">نشط</span>' : '<span class="badge bg-secondary">معطّل</span>'}</td>
                <td>
                    <button class="btn btn-sm btn-info" onclick="editItem(${item.{entity}_id})">
                        <i class="fa fa-edit"></i>
                    </button>
                    <button class="btn btn-sm btn-danger" onclick="askDelete(${item.{entity}_id})">
                        <i class="fa fa-trash"></i>
                    </button>
                </td>
            </tr>
        `).join('');
    }

    function renderPagination(meta) {
        const container = document.getElementById('{entity}-pagination');
        if (!container || meta.last_page <= 1) {
            if (container) container.innerHTML = '';
            return;
        }

        let html = '<nav><ul class="pagination">';

        // Previous
        if (meta.current_page > 1) {
            html += `<li class="page-item"><a class="page-link" href="#" onclick="loadData(${meta.current_page - 1});return false">السابق</a></li>`;
        }

        // Pages
        const start = Math.max(1, meta.current_page - 2);
        const end = Math.min(meta.last_page, meta.current_page + 2);

        for (let i = start; i <= end; i++) {
            html += `<li class="page-item ${i === meta.current_page ? 'active' : ''}">
                <a class="page-link" href="#" onclick="loadData(${i});return false">${i}</a>
            </li>`;
        }

        // Next
        if (meta.current_page < meta.last_page) {
            html += `<li class="page-item"><a class="page-link" href="#" onclick="loadData(${meta.current_page + 1});return false">التالي</a></li>`;
        }

        html += '</ul></nav>';
        container.innerHTML = html;
    }

    // ══════════════════════════════════════════════
    //  Add / Edit
    // ══════════════════════════════════════════════
    function openAddModal() {
        document.getElementById('{entity}-form').reset();
        document.getElementById('{entity}-id').value = '';
        document.getElementById('{entity}-modal-title').textContent = 'إضافة';
        new bootstrap.Modal(document.getElementById('{entity}-modal')).show();
    }

    async function editItem(id) {
        try {
            const res = await fetch(`${API_BASE}/${id}`);
            const json = await res.json();

            if (!json.success) throw new Error(json.message);

            const item = json.data;
            document.getElementById('{entity}-id').value = item.{entity}_id;
            document.getElementById('{entity}-name').value = item.name;
            document.getElementById('{entity}-description').value = item.description || '';
            document.getElementById('{entity}-modal-title').textContent = 'تعديل';

            new bootstrap.Modal(document.getElementById('{entity}-modal')).show();
        } catch (err) {
            showError(err.message);
        }
    }

    async function save() {
        const id = document.getElementById('{entity}-id').value;
        const formData = new FormData(document.getElementById('{entity}-form'));
        const data = Object.fromEntries(formData);

        const method = id ? 'PUT' : 'POST';
        const url = id ? `${API_BASE}/${id}` : API_BASE;

        try {
            const res = await fetch(url, {
                method,
                headers: {
                    'Content-Type': 'application/json',
                    'X-CSRF-TOKEN': csrfToken,
                    'Accept': 'application/json',
                },
                body: JSON.stringify(data),
            });

            const json = await res.json();

            if (!res.ok) {
                if (res.status === 422) {
                    showValidationErrors(json.errors);
                    return;
                }
                throw new Error(json.message);
            }

            bootstrap.Modal.getInstance(document.getElementById('{entity}-modal')).hide();
            showSuccess(json.message);
            loadData(currentPage);
        } catch (err) {
            showError(err.message);
        }
    }

    // ══════════════════════════════════════════════
    //  Delete
    // ══════════════════════════════════════════════
    function askDelete(id) {
        deleteId = id;
        new bootstrap.Modal(document.getElementById('{entity}-delete-modal')).show();
    }

    async function confirmDelete() {
        if (!deleteId) return;

        try {
            const res = await fetch(`${API_BASE}/${deleteId}`, {
                method: 'DELETE',
                headers: {
                    'X-CSRF-TOKEN': csrfToken,
                    'Accept': 'application/json',
                },
            });

            const json = await res.json();

            if (!res.ok) throw new Error(json.message);

            bootstrap.Modal.getInstance(document.getElementById('{entity}-delete-modal')).hide();
            showSuccess(json.message);
            loadData(currentPage);
        } catch (err) {
            showError(err.message);
        }
    }

    // ══════════════════════════════════════════════
    //  Helpers
    // ══════════════════════════════════════════════
    function debounceSearch() {
        clearTimeout(searchTimeout);
        searchTimeout = setTimeout(() => loadData(1), 300);
    }

    function escapeHtml(str) {
        const div = document.createElement('div');
        div.textContent = str;
        return div.innerHTML;
    }

    function showSuccess(msg) { /* toast */ }
    function showError(msg) { /* toast */ }
    function showValidationErrors(errors) { /* highlight fields */ }

    // ══════════════════════════════════════════════
    //  Init
    // ══════════════════════════════════════════════
    document.addEventListener('DOMContentLoaded', () => {
        document.getElementById('{entity}-form')?.addEventListener('submit', (e) => {
            e.preventDefault();
            save();
        });
        loadData();
    });

    // ══════════════════════════════════════════════
    //  Public API
    // ══════════════════════════════════════════════
    return {
        loadData,
        openAddModal,
        editItem,
        askDelete,
        confirmDelete,
    };
})();

// Global aliases
window.loadData = {Entity}Module.loadData;
window.openAddModal = {Entity}Module.openAddModal;
window.editItem = {Entity}Module.editItem;
window.askDelete = {Entity}Module.askDelete;
window.confirmDelete = {Entity}Module.confirmDelete;
window.debounceSearch = () => {};
```

## 🚨 ملاحظات للمراجعة في الاجتماع

1. **التوافقية مع JS القديم** — قد نحتاج تعديلات في الـ JS الحالي عند تغيير نمط الردود. **القرار:** نحافظ على الـ contract الحالي في الـ endpoints القديمة، ونستخدم `BaseController` للجديدة فقط.

2. **تغيير أسماء Routes** — **لا نُغيّرها دفعة واحدة.** نحتفظ بالأسماء القديمة كـ alias:
   ```php
   Route::get('/setting/customers', [CustomerController::class, 'index'])
       ->name('customers.index');  // alias قديم

   Route::get('/settings/customers', [CustomerController::class, 'index'])
       ->name('settings.customers.index');  // جديد
   ```
   ثم نحذف القديمة بعد التأكد.

3. **Form Requests قد تحتاج تخصيص** — بعض قواعد التحقق تعتمد على حقول أخرى (مثل payment_method → payment_account_id). `withValidator` يحلها.

4. **Template ملزم لكل مطور جديد** — لا استثناءات. أي شاشة بدون Template = مرفوضة في Code Review.

5. **التوثيق جزء من المهمة** — كل شاشة جديدة يجب أن تُوثّق. لا "سأوثق لاحقاً".

6. **الـ Pilot (Box) يجب أن يُنجز قبل البدء بأي شاشة أخرى** — ليكون المرجع الحي.
