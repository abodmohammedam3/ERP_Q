### 🟠 #4: `state.js` — تعقيد مفرط

**المشكلة:**

ملف كامل (200+ سطر) للتحكم بحالة أزرار 3 أوضاع (`view`, `add`, `edit`).

**مشاكل:**
- يستدعي `document.getElementById` لكل زر × 3 أوضاع
- Callback واحد فقط (`_onModeChange`)
- لا `Promise` يدعم الانتظار
- القيم hardcoded لأسماء المكونات

**الإصلاح المقترح:**
```javascript
class StateManager {
    constructor(pageId) {
        this.pageId = pageId;
        this.mode = 'view';
        this.listeners = [];  // ← متعددون
    }
    
    onModeChange(callback) {
        this.listeners.push(callback);
        return () => {
            // Unsubscribe function
            const idx = this.listeners.indexOf(callback);
            if (idx > -1) this.listeners.splice(idx, 1);
        };
    }
    
    setMode(mode) {
        if (!['view', 'add', 'edit'].includes(mode)) return;
        const oldMode = this.mode;
        this.mode = mode;
        this.listeners.forEach(fn => fn(mode, oldMode));
    }
}
```

### 🟠 #11: `item.blade.php` — `readonly` + `disabled` معاً

**المشكلة:**
```html
<input type="text" class="form-control" id="CreditAccountName"
       name="creditAccountName"
       autocomplete="off"
       readonly disabled>   ← كلاهما!
```

**الفرق:**
- `readonly`: المستخدم لا يستطيع التعديل، **لكن** يُرسل في النموذج
- `disabled`: المستخدم لا يستطيع التعديل، **و** لا يُرسل في النموذج

**مع كليهما:**
- الحقل لا يُرسل
- لكن JS قد يقرأه (`element.value`)

**السيناريو:**
- JS يعبّئ `CreditAccountName` عبر الـ lookup
- المستخدم يُرسل النموذج
- الحقل **لا يُرسل** (disabled)
- لكن `CreditAccountID` (hidden) يُرسل ✅

**في حالته:** OK لأن الـ ID هو ما يُرسل. لكن الأنماط مختلفة عن حقول أخرى.

**الإصلاح الموصى:** `readonly` فقط (بدون `disabled`).

### 🟡 #5: `lookupCache` لا يُبطَل

**المشكلة في `lookup.js`:**

```javascript
const lookupCache = {
    customers: [],
    coins: [],
    // ...
};

async function lookupEnsureLoaded(key) {
    if (lookupLoadedFlags[key]) return;  // ← لا إبطال
    // ...
}
```

**السيناريو:**
1. المستخدم يفتح النافذة → يُحمَّل العملاء
2. المستخدم يُضيف عميلاً جديداً (شاشة أخرى)
3. المستخدم يعود → **لا يرى العميل الجديد**

**الإصلاح:**
```javascript
window.lookupInvalidate = function(key) {
    const cacheKey = LookupConfigs[key]?.cacheKey;
    if (cacheKey) {
        lookupCache[cacheKey] = [];
        lookupLoadedFlags[key] = false;
    }
};

// بعد إضافة عميل:
lookupInvalidate('customer');
```

**+ إبطال تلقائي عند إغلاق الصفحة:**
```javascript
window.addEventListener('beforeunload', () => {
    sessionStorage.removeItem('lookup_cache');
});
```

### 🟢 #1: `inline onclick` في النماذج

**مثال:**

```javascript
// في JS
document.querySelectorAll('[data-action="select-currency"]').forEach(btn => {

        Currency.select(
            btn.dataset.id,
            btn.dataset.name,
            btn.dataset.rate
        );
    });
});
```
